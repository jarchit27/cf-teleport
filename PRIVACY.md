# Privacy Policy for CF Teleport

**Effective Date:** August 2026

CF Teleport is committed to protecting your privacy. This privacy policy explains how data is handled by the CF Teleport Chrome Extension and VS Code Extension.

## 1. Data Collection & Usage
* **No External Data Collection:** CF Teleport does not collect, track, store, or transmit any personal data, web history, or user information to external servers.
* **Local Operation Only:** All data extracted from Codeforces problem pages (problem statements and sample test cases) is processed 100% locally on your computer and sent directly to your local VS Code environment via `http://localhost`.

## 2. Permissions
* `activeTab` & `scripting`: Used strictly to parse the problem statement and test cases from the active Codeforces tab when you click the extension button.

## 3. Third-Party Sharing
CF Teleport does not sell, share, or transfer any user data to third parties.

## 4. Contact
If you have any questions about this Privacy Policy, you can open an issue on our GitHub repository:  
https://github.com/jarchit27/cf-teleport/issues
